자기소개

  • React·TypeScript를 주력으로, 아파트·오피스텔 커뮤니티 플랫폼에서 입주민 앱·운영 콘솔·관리자 운영툴·매장 POS·사이니지 CMS 등 6개 제품을 병행 담당했습니다.
  • 최근에는 사람이 매번 기억하고 판단하던 일을 기계가 대신하게 만드는 데 집중했습니다.
  • OpenAPI 스펙에서 타입을 생성해 수기 정의를 없앴고, ADR·LLM Wiki로 결정 근거를 사람과 AI가 함께 읽도록 정리했습니다.
  • 직전 회사에서는 웹팀 리드로 3개 제품을 런칭하며 CI/CD와 코드 리뷰 프로세스를 세웠습니다.

핵심 역량

  • 개발 품질 검증 자동화 프로세스 확립

    OpenAPI 스펙 기반 API 타입 자동 생성 체계를 4개 제품에 도입해 수기 타입 정의를 없앴습니다. CI 파이프라인에는 Knip 기반 미사용 코드·파일 검증을 붙여, PR로 새로 죽은 파일이 생기면 그 원인이 된 줄에 리뷰 코멘트가 달리도록 직접 구현했고 DeadCode 발생률을 11.54%에서 1% 미만으로 낮췄습니다.

  • AI 기반 바이브 코딩 인프라 구성

    ADR·SPEC·BUGS 세 축으로 AI가 읽는 문서를 분류·규격화하고, 코드를 고칠 때 어떤 문서를 갱신할지 파일별·행위별로 규정한 트리거 표를 설계해 개발 문서 갱신을 자동화했습니다. 저장소별 에이전트 규칙 21건 중 18건, ADR 34건 중 31건을 최초 작성했습니다. AI 접근 권한을 세분화하고, 저장소에 두던 민감 정보를 CD 파이프라인으로 이관했습니다. 사내 코드베이스와 별개로 제 작업 환경에서는 PreToolUse 훅을 걸어, 브랜치 최초 push 직전 셀프 코드리뷰를 통과해야 나가도록 했습니다.

  • 빌드·의존성 최적화와 Turborepo 공용 설정 체계 확립

    CRA에서 Vite로, npm에서 pnpm으로 3개 제품을 동시 전환해 같은 장비 기준 빌드 262초 → 13초, 의존성 설치 230초 → 4초로 단축했습니다. Turborepo 위에 공용 설정 패키지(config-typescript·config-tailwind·config-prettier·eslint-config)를 분리해 제품 간 설정을 단일 소스로 통합했습니다.

  • Sentry 관측성 구축 — 사후 대응에서 사전 인지로

    Sentry를 도입하고 에러 바운더리에서 리포팅 로직을 분리했습니다. 노이즈 필터링과 단지·사용자 태깅, 샘플 레이트 튜닝으로 장애 인지 경로를 고객 문의 접수에서 모니터링 알림으로 바꿨습니다.

  • 멀티 브랜드·멀티 클라이언트 구조 설계

    앱·웹·POS·사이니지 등 6개 제품을 병행 담당하며, 건설사 브랜드마다 다른 단지 앱을 코드 한 벌로 서비스하는 구조를 설계했습니다.

  • 팀 리딩 — 규격 수립과 팀 확산

    웹팀 리드로 3개 제품을 런칭하며 CI/CD와 머지 전 코드 리뷰 프로세스를 세웠습니다. 현 조직에서는 동료 PR 1,501건을 리뷰했고(본인 PR 629건의 약 2.4배), ADR 34건 중 31건, 버그 원인 분석 97건 중 58건을 먼저 써서 규격의 본을 만들고, 팀원 4명이 같은 형식으로 이어 갱신하도록 제안해 정착시켰습니다.

역할

성과
  • 건설사·브랜드마다 개별 구축하던 단지 앱을 단일 코드베이스로 동시 서비스하도록 구조 설계
  • 차세대 버전을 클라이언트·단지·사용자 3계층 권한 체계로 전면 개편하고, 6차 통합 테스트를 거쳐 예정 일정에 출시
  • 계정 ID 길이 제약으로 스마트홈 연동이 불가하던 사용자군을 OAuth 콜백 구조 재설계로 해소

  1. 멀티 브랜드 대응 구조 설계

    클라이언트·단지·사용자 3계층 권한 체계를 상품(구독) 단위 관리 체계로 반영하고, 메뉴 관리 체계를 구 시스템에서 신규 운영 콘솔로 완전히 이관했습니다. 홈 화면과 전체 UI/UX를 재설계하며 다크 모드를 도입했고, 6차에 걸친 통합 개발 테스트에서 라운드별로 도출된 결함 약 70건을 처리했습니다.

  3. 스마트홈(홈넷) OAuth 콜백 구조 재설계
  4. 도메인 기능 개발

    전기차 충전 상태 조회, 방문차량 알림, 알림센터, 지도 기반 위치 기능을 개발했습니다. 국제화(i18n)와 시스템 설정에 연동되는 다크 테마, PDF·전자서명·카메라 등 디바이스 연동을 담당했습니다.
