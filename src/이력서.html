프론트엔드 개발 2024.01 ~ 재직 중

아파트·오피스텔 커뮤니티 플랫폼. 입주민 앱·사내 운영 콘솔·관리자 운영툴·매장 POS·주문 키오스크·디지털 사이니지 CMS 6개 프론트엔드 제품 병행 담당. 제품 개발과 별개로 프론트엔드 플랫폼과 개발 자동화 기반 구축.

성과
  • 6개 제품 중 디지털 사이니지 CMS는 프론트엔드 1인으로, 현장 지원 데스크톱 앱은 단독으로 초기 구축부터 운영 투입까지 수행
  • 사이니지 CMS 운영 투입 후 4개월간(2025.05~08) 결함 87건 처리 — 해당 기간 이 제품 결함의 97%
    • 결함 해결 리드타임 중앙값 26.4시간 → 2.3시간 (91% 단축)
    • 결함 유입 월 39건 → 16건 (59% 감소) · 첫 달은 출시 직후 집중 검수분 포함
    • 2025.09 이후는 제품 종료 단계로 잔여 과제 위주 — 이 구간과 분리
  • self-hosted 러너의 직렬 PR 검증 체인 병렬 분기 및 정적 분석 워크플로 흡수
    • 검증 완료 시간 중앙값 8.1분 → 2.8분 (66% 단축)
    • 상위 10% 구간 21.1분 → 4.0분 (81% 단축)
  • 단지 개설 초기 설정을 콘솔 일괄 흐름으로 통합해 수행 주체를 개발자에서 기술영업팀으로 이관
    • 출입카드·세대·시설·예약 대상·현장 기기 등록에 개발자가 들어가지 않음
  • 배포 자격증명을 개인 액세스 토큰에서 조직 GitHub App 설치 토큰 체계로 9개 저장소 일괄 전환
    • 담당자 이탈과 무관한 배포 체계 확보
