# tools — 산출물 생성기

`src/*.html` 이 원본이고, 여기 스크립트가 나머지를 만든다. 실행은 저장소 루트에서 `make`.

| 스크립트 | 하는 일 | 출력 |
|---|---|---|
| `h2md.py` | HTML → 마크다운 | `../private/현재본-md/*.md` (사람이 읽는 용) |
| `saramin.py` | 이력서 → 채용 폼 붙여넣기용 평문 | `../private/현재본-md/사람인-붙여넣기.txt` |
| `check.py` | 회귀 검사 | 수치 중복(이력서 한정) · 정직성 표지 잔존 |

`check.py` 의 **수치 중복 규칙은 이력서(index.html)에만** 적용한다.
경력기술서·포트폴리오는 '서술 + 지표 표' 반복이 설계된 구조라 중복이 정상이다.

출력 대상 `private/현재본-md/` 는 저장소 안이지만 **`.gitignore` 대상**이다. 이 저장소는
GitHub Pages 로 공개되는데 Pages 는 커밋된 것만 게시하므로, 무시되는 한 사내 이슈 수·
리드타임이 밖으로 나가지 않는다 — `private/정량지표-실측결과.md`(실측 원장)와 초안류도
같은 이유로 `private/` 안에 둔다.
